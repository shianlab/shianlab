## 关于我

我是一个 **00 后｜OPC｜AI 应用开发者**。现在围绕 AI 做自己的项目和服务，也在认真练习一种更自由的工作方式：一个人，但不只是一个人；借助 AI、工具和一套更好的方法，把想做的事情做得更远一点。

我不太迷恋“新工具出现了”这件事本身。真正让我着迷的是，工具进入具体场景之后，能不能让人少一点重复、少一点混乱，多一点把事情做成的确定性。

## 我相信的事

信息整理不是把东西收得整齐，而是帮一个人重新获得判断力。内容表达也不是把话说得很响，而是让真正值得被听见的东西，找到它该去的地方。

所以除了开发，我也做内容、组织活动、做分享，和同频的人一起交流。我是 INTJ，平时偏安静研究型，但对有意思的想法有很强的表达欲。一个人闷头做事很好，和一群认真做事的人互相点亮，也很好。
